**Create: Getting Hot** — это неофициальный аддон для технической модификации *Create*, который расширяет механику взаимодействия с температурами, теплогенерацией и термодинамикой. 

> [!NOTE]
> Данный мод находится в активной разработке. Базовая заготовка создана на основе официального шаблона NeoForge MDK.

---

## 🔥 Особенности (Features)

* **Продвинутая термодинамика:** Новые способы генерации, удержания и передачи тепла для ваших фабрик.
* **Интеграция с Create:** Полная совместимость с котлами (Boilers), двигателями Стирлинга и другими теплозависимыми механизмами.

---

## 🛠️ Установка и Разработка (Installation & Setup)

Если вы хотите клонировать этот репозиторий для доработки или изучения кода:

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   ```
2. **Откройте проект** в любой современной IDE (рекомендуется *IntelliJ IDEA* или *Eclipse*).
3. **Для пользователей Eclipse/остальных IDE (кроме IntelliJ):** перед запуском конфигураций выполните команду в терминале:
   ```bash
   ./gradlew ideBeforeRun
   ```

### Решение проблем
Если у вас отсутствуют зависимости или возникли ошибки сборки, очистите кэш и обновите их:
```bash
./gradlew gradlew --refresh-dependencies
./gradlew clean
```
